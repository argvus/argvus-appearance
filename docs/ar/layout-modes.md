`argvus layout-mode-menu` (SUPER + Shift + M): **Tab / Shift+Tab**: Sticky/Spaced ⇄ Tile/Floating · Taskbar Top/Bottom. اختر Sticky أو Spaced بالسهمين ↑/↓. تجمع البطاقات الأربع يمينًا بين النوافذ المتجانبة أو العائمة وشريط المهام في الأعلى أو الأسفل؛ يتنقل ↑/↓/←/→ بينها دون تكرار. انقر للاختيار، واضغط Enter للتطبيق أو Escape للإلغاء. يظهر الوضع غير المحدد باهتًا وتستخدم المعاينات السمة والخلفية الحاليتين. تبقى التطبيقات المعلقة ظاهرة ويمكن إعادة المحاولة عند الخطأ.

تعرض محددات السمات والأوضاع التقدم داخل نافذتها دون شاشة تحميل الجلسة. تُجهز مواضع شريط المهام النهائية قبل إعادة التحميل، وتُجمع عمليات إعادة التشغيل اللازمة في معاملة systemd واحدة.
