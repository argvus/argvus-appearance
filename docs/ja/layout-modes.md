---
title: レイアウトモード
description: Sticky または Spaced のデスクトップレイアウトを選択してください。
---
Sticky はウィンドウやシェルの表面をコンパクトに保ちます。Spaced はより大きな間隔、丸みを帯びた角、広いタスクバーマージンを使用します。レイアウトモードは選択されたテーマに依存せず、モードを変更するとそのモードのジオメトリが再適用されます。

**コントロールセンター → 外観 → デスクトップ → 外観モード** でモードを選ぶか、`SUPER + Shift + M` でピッカーを開きます。標準設定は `/layout/variant` で、値は `sticky` と `spaced` があります。解決された Spaced テーマ ID は `-spaced` サフィックスを使用します。既存の `float` 値および `-float` ID は互換性のために引き続き読み取り可能です。
